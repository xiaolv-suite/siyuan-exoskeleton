## 一、 核心设计四大铁律 (Design Philosophy)

1. **围绕增强思源，增强笔记本身**：绝不为了功能而功能，每一项能力都直指「让笔记输入更快、让笔记检索更准、让双链构建更顺畅、让本地文件与双链知识网络浑然一体」；
2. **开放工具适配，不绑架用户习惯**：先做能力抽象，优先调动用户电脑上已安装并习惯的软件（如 Listary、Everything、PixPin、Snipaste、SumatraPDF、Zotero 等），由外骨骼将它们的结果无感衔接进思源，同时自带零依赖离线引擎保底；
3. **明确定位：外部辅助与前置清洗**：思源内部已有成熟的原生编辑器与 AI 智能体，外骨骼专注于「外部系统环境感知、剪贴板杂质清洗、元数据嗅探、意图分流与双链桥接」；
4. **纯粹的外骨骼，一切资产回归思源原生标准**：0ms 呼出、用完即走，所有产物纯粹落盘在思源的原生标准（`.sy` 块树、Block IAL 属性、SQLite 数据库、assets 资产库、标准 Markdown 双链）。

## 二、 核心能力全景矩阵 (v3.0.0 最新演进)

### 1. ★ 全面摆脱外部依赖，进化为纯 C# 原生高性能单文件应用
- **单 EXE 内嵌应用资源 (`思源外骨骼.exe`)**：前端离线资产、SVG 图标及 `WebView2Loader.dll` 嵌入主程序；系统仍需安装 WebView2 Runtime。需要快速热更新时可使用同级 `assets` 目录；
- **WebView2 空闲资源管理 (`MemoryOptimizer.cs`)**：通过 WebView2 挂起、Win32 工作集修剪和 CLR 垃圾回收降低空闲资源占用；实际数值取决于功能、WebView2 Runtime 与主机环境；
- **零插件中转直连内核 (`SiYuanClient.cs`)**：彻底注销小驴快门等内部代理插件，基于高性能连接池直通思源 REST API 与 SQLite；支持 IPv4 (`127.0.0.1`) / IPv6 (`[::1]`) 双环回智能穿透；
- **离岸缓冲队列兜底 (`OfflineQueueManager.cs`)**：思源未开机或暂时离线时，速记会尝试写入当前 Windows 用户 DPAPI 加密队列；队列写入失败会明确提示，思源恢复后周期性重试补录。
- **队列状态可核对**：读取/解密异常显示“队列异常”，保留原文件；回写与清空等待实际回执，部分失败显示剩余记录。文件队列显示其原路径及指定目标文档。

### 2. ★ 本地 Office (Word / Excel / PPT) 零依赖流式透视与双向锚点 (`OfficeOpenXmlParser.cs`)
- **零第三方依赖极致轻量 (<30ms · <8MB 内存)**：纯基于 .NET 4.8 内置 `ZipArchive` + `XmlReader` 纯流式解包，无任何外部 DLL，电脑即使未装 Office/WPS 亦可毫秒级透视内容；
- **Word 大纲树与审阅批注转待办**：毫秒级提取 H1~H6 大纲树，一键复制或沉淀入日记；自动将审阅批注与引文提取为 `- [ ] (审阅人 · 时间): 批注 \n > 原文` 法务与学术修改 Checklist；
- **Excel 多工作表透视与转属性视图 (AV)**：自动提取工作表、行数列数并生成 Markdown 表格预览，支持 1 键转为思源原生交互式属性视图数据库；
- **PPT 幻灯片与演讲备注转 FSRS 闪卡**：自动扫描演讲者口述备注（Speaker Notes），正文为卡片正面、演讲备注为卡片背面，1 键生成 FSRS 问答闪卡库；
- **跨软件深层定位穿透**：支持通过 `siyuan-exoskeleton://open-office` 穿透跳转至 Excel 具体单元格（如 `Sheet1!C15`）及 Word 小节标题。

### 3. ★ 本地 Office & PDF 内核级实时热重载感知 (`OfficeFileWatcher.cs`)
- **Windows 内核级变更感知**：依托原生 `ReadDirectoryChangesW` 内核事件（0% CPU，<50KB 内存），毫秒感知外部 Word / Excel / PPT / PDF 文档修改保存；
- **多阶段落盘 800ms 防抖**：精准过滤 Office 临时互斥锁文件（形如 `~$Doc.docx`），等待外部多阶段文件流写入完毕后触发；
- **有界容量保护与动态热重载**：支持上限 150 篇活跃文档热监听保护；当外部文档保存时，Bento 便当盒抽屉自动多态刷新（Office 抽屉或 PDF 研读大纲），并弹出气泡轻通知。

### 4. ★ 微软 Office 与金山 WPS COM 运行态晚绑定桥接器 (`OfficeComBridge.cs`)
- **零破坏剪贴板直读**：通过 COM `Marshal.GetActiveObject` 晚绑定直读选区，不向系统注入 `Ctrl+C`，保护用户剪贴板数据完整性；
- **全系办公套件覆盖**：
  - Microsoft Word (`winword`) 与 WPS 文字 (`wps` / `kwps`)
  - Microsoft Excel (`excel`) 与 WPS 表格 (`et` / `ket`)：自动捕获单元格选区地址（如 `Sheet1!B2:D10`）并将区域转为 Markdown / TSV
  - Microsoft PowerPoint (`powerpnt`) 与 WPS 演示 (`wpp` / `kwpp`)：自动提取当前演示文稿物理路径与当前浏览幻灯片索引（如 `Slide3`）；
- **纯反射晚绑定**：无需安装或引用 `Microsoft.Office.Interop`，未装对应办公软件时安全降级，绝不报错。

### 5. ★ 本地学术 PDF 极速流式透视与研读大纲引擎 (`PdfLightParser.cs`)
- **零依赖 PDF 首尾采样嗅探**：流式读取 PDF 头部 32KB 与尾部 64KB，在 <5ms、<500KB 内存下提取：
  1. 总页数 (`/Pages /Count`)
  2. 文献标题与作者元数据 (`/Title` / `/Author`)
  3. 章节目录书签大纲 (`/Outlines` / TOC)；
- **SumatraPDF & Edge 页码精准穿透**：生成携带 `siyuan-exoskeleton://open-pdf?path=...&page=N` 深度锚点的读书清单，联动 SumatraPDF (`-page N`) 或 Edge (`#page=N`) 秒级原位翻至对应页码；
- **自动纳入热同步**：解析同时自动挂载 `OfficeFileWatcher` 监听底稿保存。

### 6. ★ 零依赖原生 Office 逆向导出引擎 (`OfficeExporter.cs`)
- **纯手工 OpenXML 生成**：基于纯 `System.IO.Compression.ZipArchive` 动态生成标准的 `[Content_Types].xml`、`_rels/.rels`、`word/document.xml` 与 `xl/worksheets/sheet1.xml`；
- **Word (.docx) 导出支持**：标准 H1~H3 样式、段落换行、加粗斜体代码、待办复选框（`☐`/`☑`）、引用块（左侧强调边框）及标准网格表格；
- **Excel (.xlsx) 导出支持**：标准多行多列表格数据生成，自动行内字符串净化；
- **行内 Markdown 语法标签净化 (`CleanInlineMarkdown`)**：导出前自动剥离 `**加粗**`、`*斜体*`、`[超链](url)`、`((block_id "文本"))` 等原生标记，保持 Word 与 Excel 文档排版整洁。

### 7. ★ 开发者 IDE 工程与活动源文件上下文感知 (`ContextPerception.cs`)
- **原生窗口启发式嗅探**：通过 Windows 句柄即时解析开发者前台工作区：
  - **VS Code / Cursor**：自动提取活动代码文件名与工作区项目名（如 `App.cs` · `siyuan-exoskeleton`）；
  - **JetBrains 全家桶**：支持 PyCharm、IntelliJ IDEA、WebStorm、Rider；
  - **Visual Studio**：自动匹配解决方案名与当前源码文件；
- **知识网络原生注水**：在速记时自动生成 `[🚀 #项目名]` 标签，并注入 `custom-project-name` 与 `custom-active-file` 原生 IAL 属性，代码片段与研发笔记完美挂钩。

### 8. ★ Windows 资源管理器原生双右键菜单 (`ShellContextMenuManager.cs`)
- **系统级免开窗流式联动**：在任意文件上右键，直接呼出外骨骼：
  1. **`思源外骨骼 · 透视与归档入笔记`** (`-sendfile "%1"`)：Word/Excel/PPT/PDF 自动提取大纲、生成跳转锚点并写入当日日记，自动启动外部热监听；普通文件极速归档入库；
  2. **`思源外骨骼 · 桌面全景透视抽屉`** (`-inspect "%1"`)：秒级唤起 Bento 便当盒全景透视抽屉供交互式研读与查阅；
- **双协议与命令行全打通**：支持外部协议 `siyuan-exoskeleton://inspect?path=...` 与命令行 `-inspect` / `--inspect` 参数。

### 9. ★ 深度对标与超越叶归「一键记事」（连续记录防碎块粘滞 & 意图微感应 HUD）
- **防碎块粘滞时间窗口 (Continuation Window)**：默认提供 30 秒（可在设置自由调节 0~600 秒）的连续记录粘滞期。在同窗口同应用下连续速记自动合并至上一条块内，彻底告别“一句话一个日记块”的碎片化痛点；
- **动态意图微感应 HUD (`MiniInputWindow`)**：按下 `Alt+Shift+S` 唤出的居中速记框键入 `!`、`@`、`?`、`#` 时左侧徽标与边框实时平滑变色感应（待办/人脉/闪卡/项目），处于粘滞期时自动亮起 `⏳ 续写合并` 提示；
- **`[[` / `【【` 知识库双链实时补全**：在速记框键入 `[[关键词` 时，3ms 异步检索思源知识库文档与重点段落，按 Tab 或点击候选词直接完成 `((block_id "标题"))` 双链闭环；
- **多行草稿微舱扩展 (Scratchpad Mode)**：在速记窗按 `Ctrl+Enter` 瞬间展开为 175px 多行记事舱，支持多行 Markdown、任务清单批量解包入库；支持失焦草稿防误关保护；
- **桌面图钉便签 HUD (`ShowStickyNote`) 实时双向回写**：搜索抽屉中点击 `📌 钉在桌面`，将笔记块钉在屏幕右上角供写代码或文献时对照参考；支持点击图钉切换置顶、`Ctrl+S` 即时回写思源原生块，并支持 `Ctrl +/-` 缩放阅读字号。

### 10. ★ 桌面级 0ms FSRS 闪卡 3秒微刷卡微舱 (`FSRSCapsuleWindow` · `Alt+Shift+R`)
- 深度联动思源原生 `/api/riff/` 间隔重复算法，彻底解决用户“卡片堆积不复习”的痛点；
- 按下 `Alt+Shift+R` 0ms 居中弹出 540×360 极简微舱，展示卡片正面，空格翻转答案，数字键 `1 / 2 / 3 / 4` 秒级评级（重来/困难/良好/简单），无需切换思源大窗口，碎片时间轻松刷完。

### 11. ★ 全局双链认知雷达与随身划笔穿透 (`CapsuleWindow` · `Alt+Shift+W`)
- 划选即知知识关联：在任意软件划选词汇呼出微胶囊时，以 3ms 极速反查思源 SQLite 数据库；
- 若词汇已在思源建档收录，胶囊顶栏瞬间亮起翠绿微徽章：`🔗 已收录: 《深度学习笔记》 (Shift+↵ 贴双链)`，按 `Shift+Enter` 即可将双链注入外部光标；
- 边界自适应翻转：当光标靠近屏幕右缘或下缘时，微胶囊**自动向左/向上翻转**，保证在任何异构屏幕划词均紧密贴合光标。

### 12. ★ 深度对标 Obsidian/Cubox/Readwise：0扩展双态剪藏与即时批注 (`g:`)
- **零浏览器扩展限制**：通过 Windows 底层 UI 自动化与窗口感知，0ms 嗅探 Edge、Chrome、Brave、Firefox 等全系浏览器乃至桌面客户端；
- **双态自由分流**：
  - **模式 1 (Enter · 默认)**：**文献卡片流** —— 将文章元数据、划选精粹生成大纲级嵌套列表归入今日日记或收集箱；
  - **模式 2 (Shift+Enter)**：**独立研读专页** —— 在 `/读库/` 中创建整篇独占笔记，生成思源原生文献 Callout 看板，自动挂载 `custom-clip-status="unread"` 拾遗未读分拣属性；
- **即时思考批注**：搜索框直接键入 `g: 你的思考观点`，在剪藏原文同时自动以子列表或专页批注区归档「摘录+思考」双闭环；
- **14 大主流知识平台智能元数据与标签**：深度适配微信公众号、知乎专栏/问答、B站、GitHub、arXiv、少数派、掘金、CSDN 等，自动提取真实作者并注入专属 Emoji 与智能标签；
- **防盗链外链图片自动本地落盘**：静默伪造合规 Referer 将微信公众号、知乎等易失效图床图片自动下载并上传至思源 `/data/assets/` 资产库，彻底根绝 403 访问被拒与死图。

### 13. ★ 开放本地工具适配：Everything / Listary / Zotero / 截图工具自由选用 (`ToolDetector.cs`)
- **绝不绑架用户习惯**：无论是习惯用 **Listary**（快速激活检索）还是 **Everything**（全盘毫秒索引），系统均可秒级感知并设为首选引擎；
- **学术生态联动**：深度感知 **Zotero** 学术文献库与 **SumatraPDF**，支持 `zotero:` 前缀与 `zotero://` URI 原位激活调动；
- **截图工具自由选择**：自动探测 **PixPin**、**Snipaste** 或内置硬件加速引擎，设置页提供状态探针一键切换。

### 14. ★ 本地极速调用桥与 Quicker / AutoHotkey / Raycast Webhook 回路 (`ExternalApiBridge.cs`)
- **本地环回服务 (`127.0.0.1:43989`)**：基于 .NET 内置 `HttpListener` 提供 Webhook 接口，默认关闭；
- **多端与外部宏工具一键直通**：
  - **`POST /api/capture`**：支持 Quicker、AutoHotkey、Stream Deck、本地 Python/Shell 脚本一键免切窗速记，自动携带来源软件与标题，无感追加今日日记；
  - **`GET /api/today` & `GET /api/tasks`**：免开思源客户端瞬时透视今日时间流及全库未完成待办；
  - **`POST /api/show`**：支持指定唤起总控工作台、随身划笔或 FSRS 闪卡微舱；
- **严密本地安全隔离**：默认关闭；启用后必须配置安全令牌，所有请求都需在 `X-Token` 或 Bearer 头中鉴权，浏览器 CORS 仅允许环回来源。

### 15. ★ 数据表格与属性视图 (AV 数据库) 智能转换与排版引擎 (`TableToAvConverter.cs`)
- **多源表格智能解包**：秒级识别剪贴板或文档内的 Markdown 表格、TSV（从 Excel/WPS 复制的制表符栅格）、CSV 逗号分隔文本；
- **列字段数据类型推导**：70% 启发式统计自动推导列属性：`number`（数值/货币/百分比）、`date`（日期）、`checkbox`（布尔复选）、`url`（网址）与 `text`（文本）；
- **美化对齐与思源大纲折叠**：
  - 数值自动右对齐 (`---:`)、日期/复选居中对齐 (`:---:`)、文本左对齐 (`:---`) 生成标致的 GitHub 标准表格；
  - 提供 Tier 2 降级保底：1 键转为原生层级折叠列表大纲；
- **双向数据打通**：支持 1 键将数据表格生成标准 Excel `.xlsx` 文件并在本地秒开，或转为思源原生 Attribute View 数据库结构。

### 16. ★ 极速命令行 CLI 调度器 (`Command Line Dispatcher`)
- **秒开瞬结免 GUI 启动**：后台常驻守护时，外部程序或终端通过 CLI 调用瞬间完成记事并秒退（<15ms）：
  - `思源外骨骼.exe -add "灵感记事"` / `-note "内容"`：直投今日日记；
  - `思源外骨骼.exe -todo "待办事项"`：自动转为任务清单 `- [ ] 待办事项`；
  - `思源外骨骼.exe -card "正面问题 // 背面答案"`：自动写入问答闪卡；
  - `思源外骨骼.exe -panel` / `-pen` / `-fsrs` / `-clip` / `-status`：瞬时调起对应界面或刷新状态。

### 17. ★ 浮墨漫游回顾与那年今日灵感唤醒 (`FlashbackManager.cs`)
- **历史旧笔记温情复现 (flomo/Readwise 启发)**：告别“只记不看”，SQLite 纳秒级打捞历史优质灵感块 (15~300 字)；
- **优先激活「那年今日」**：智能匹配历史同月同日的历史日记与思考，支持 1 键原位追加重温思考或在思源大窗中原位定位。

## 七、 隔离自动化检查 (E2E Testbench)

思源外骨骼自带隔离自动化检查脚本 (`scripts/e2e-isolated.mjs`)。每次运行会报告实际执行的检查数量；检查混合了隔离内核/API、C# 核心逻辑和源码结构断言，不代表相同数量的真实桌面交互：

```bash
# 启动专用隔离内核沙箱 (随机端口) 自动化检查
pnpm e2e:isolated
```

- 检查包含冷启动、速记写入、意图分流、搜索、文件处理、Webhook、写回和离线队列等路径。运行报告应区分隔离内核/API、逻辑检查、静态结构断言与真实 Windows/WebView2 用户交互；真实主机和外部提供方验收需另行记录。
- 测试使用随机临时工作区、独立应用数据目录、随机内核与 Webhook 端口；隔离模式跳过系统协议、资源管理器菜单、全局热键、鼠标钩子和托盘注册，退出时只结束本次启动的子进程并清理本次临时目录。
- `XIAOLV_WORKSPACE_DIR` 指定隔离测试的本地工作区；显式 `SIYUAN_URL` 不会借用生产令牌或资产路径。测试配置和书签使用虚构样本，音效关闭；涉及系统注册、全局输入和外部应用启动的检查仅验证静态契约，实际桌面联动需单独验收。
- 请串行运行隔离 E2E；测试实例的 IPC 管道与互斥锁尚未按每次运行区分。`test:ui:headless` 使用独立 Chrome 配置与后台页面，可检查 Tab 顺序、模态输入隔离、队列失败反馈及 880/920/1280 视口布局。
