# 思源外骨骼剪藏伴侣（浏览器扩展 · MV3）

浏览器侧轻量剪藏入口：**选中文字右键 / 一键整页收藏 → 经本机思源外骨骼 webhook 直写思源今日日记**。无云端、无账号、无第三方中转——对标 Obsidian 官方 Web Clipper 的「片段模式 + 整页模式」，数据只走 127.0.0.1。

## 安装（Chrome / Edge / Arc 等 Chromium 系）

1. 打开 `chrome://extensions`（Edge: `edge://extensions`）
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录（`browser-extension/`）
4. 点扩展图标的「选项」→ 填入 Webhook Token（思源外骨骼 → 偏好设置 → Webhook 令牌）→ 「测试连接」显示 ✓ 即就绪

## 用法

| 操作 | 入库结果 |
|---|---|
| 选中网页文字 → 右键「📑 存入选中文字到思源」 | 标题链接 + 选区文字进入今日日记「🌐 网页剪藏」小节 |
| 页面空白处右键「🌐 收藏此网页到思源」 | 标题 + URL 进日记 |
| 点扩展图标 → 可写一句批注 → 「📑 整页收藏」 | 标题 + URL + 批注进日记 |
| 点扩展图标 → 「📋 仅复制 Markdown 链接」 | 复制 `[标题](URL)` 到剪贴板，随处可贴 |

## 依赖

- 思源外骨骼桌面端运行中（Webhook 默认端口 43989，可在偏好设置修改）
- Webhook Token 与端口一致（扩展选项里可改）
