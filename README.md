## 一、 核心设计四大铁律 (Design Philosophy)

1. **围绕增强思源，增强笔记本身**：绝不为了功能而功能，每一项能力都直指「让笔记输入更快、让笔记检索更准、让双链构建更顺畅」；
2. **开放工具适配，不绑架用户习惯**：先做能力抽象，优先调动用户电脑上已安装并习惯的软件（如 Listary、Everything、PixPin、Snipaste、SumatraPDF 等），由外骨骼将它们的结果无感衔接进思源，同时自带零依赖离线引擎保底；
3. **明确定位：外部辅助与前置清洗**：思源内部已有成熟的原生编辑器与 AI 智能体，外骨骼专注于「外部系统环境感知、剪贴板杂质清洗、元数据嗅探、意图分流与双链桥接」；
4. **纯粹的外骨骼，一切资产回归思源原生标准**：0ms 呼出、用完即走，所有产物纯粹落盘在思源的原生标准（`.sy` 块树、Block IAL 属性、SQLite 数据库、assets 资产库、标准 Markdown 双链）。

## 二、 核心升级特性 (v2.9.0 深度架构现代化)

### 1. ★ 全面摆脱外部平台限制，进化为纯 C# 原生高性能单文件应用
- **纯单文件自给自足 (`思源外骨骼.exe`)**：内嵌全部前端离线资产、SVG 图标与 `WebView2Loader.dll`，单一可执行程序仅 **3.03 MB**，解压或单文件运行皆可，无环境安装负担；
- **5 级极限内存制冷引擎 (`MemoryOptimizer.cs`)**：Chromium 裁剪 + WebView2 隐匿挂起 (`TrySuspendAsync`) + Win32 工作集深度修剪 + CLR LOH 垃圾回收紧缩，空闲常驻内存低至 **~2.1 MB**（CPU 0.0%）；
- **零插件中转直连内核 (`SiYuanClient.cs`)**：彻底注销小驴快门等内部代理插件，基于高性能连接池直通思源 REST API 与 SQLite；支持 IPv4 (`127.0.0.1`) / IPv6 (`[::1]`) 双环回智能穿透；
- **离岸缓冲队列 100% 自动兜底 (`OfflineQueueManager.cs`)**：思源未开机、升级重启或断网时，速记笔记自动落入本地加密缓冲，思源上线后静默自动合流补录，绝不丢字。

### 2. ★ 动作深度聚焦与归并（精炼 25 款王牌心流矩阵）
- 彻底剔除冗余代码与散装马甲，精炼归并为 **极速捕获 (6) + 检索双链 (6) + 生态直达 (8 · Alt+1~8) + 格式心流 (3) + 运维体检 (2)** 共 25 款王牌卡片；
- 彻底清除 14.6KB 的 Quicker 遗留动作商店死代码，前端加载速度跃升至毫秒级。

### 3. ★ 可视化快捷键录制控件 (Visual Hotkey Recorder)
- 设置面板彻底淘汰手动键入字符串的繁琐体验：用户只需点击输入框，直接在键盘上按下组合键（如 `Ctrl+Alt+S`）；
- 自动智能聚合修饰键（Ctrl/Alt/Shift/Win）与主键，按 Esc 取消，按 Backspace 清除；
- 录制后以 200ms 防抖自动联动底部的 **Win32 冲突探针医生 (`HotkeyConflictManager`)**，实时检测是否被微信/QQ/PixPin占用，并给出可用替代键建议。

### 4. ★ Per-Monitor DPI V2 异构多屏自适应 (`WindowPositionHelper.cs`)
- 动态获取当前鼠标所在屏幕的 Windows 有效 DPI 缩放比（100%~200%），准确将物理像素换算为 WPF DIPs 并实施安全边缘夹紧；
- **随身划笔智能自适应跟随 (`PlaceNearCursor`)**：彻底修复多显示器、副屏负坐标场景下的跨屏飞跃 Bug；当光标靠近屏幕右缘或下缘时，微胶囊**自动向左/向上翻转**，保证在任何异构屏幕划词均紧密贴合光标。

### 5. ★ 剪贴板历史管道扩容至 30 条与多态分类筛选 (`c:` / `clip:`)
- `ClipboardWatcher.MaxRecentCount` 正式由 15 条扩充至 **30 条**；
- 输入 **`c:url`** 仅看网页链接、**`c:code`** 仅看代码块、**`c:table`** 仅看数据表格、**`c:cite` / `c:academic`** 仅看学术文献 (DOI/arXiv)、**`c:math`** 仅看 LaTeX 数学公式、**`c:img`** 仅看截图图片；
- **全网学术文献嗅探与元数据自愈**：复制 DOI（如 `10.1038/...`）或 arXiv 论文编号（如 `2312.00752`）时，自动异步拉取 CrossRef 或 arXiv 官方题录与主要作者，生成带 `custom-literature-doi` 的标准文献卡；
- **LaTeX 核心公式智能识别**：自动嗅探 `\frac`, `\int`, `\sum` 等数学公式宏命令，自动格式化为标准 KaTeX `$$` 原生块语法；
- **多空格对齐数据表格自愈**：支持无缝识别控制台输出与 OCR 识别的多空格对齐表格并转为 Markdown 交互表格；
- 输入 **`c:关键词`** 进行全文内容模糊检索，配合 **`Shift+Enter`** 瞬间原位穿透贴入外部光标处。

### 6. ★ 属性视图 (AV 数据库表格) 专属抽屉看板 (`renderAvInspector`)
- 在主面板输入 `av:` 即可调出全库属性视图表格；
- 右侧抽屉即时展示数据库所属文档全景路径与 AV 块 ID；
- 输入 `av:表名 内容` 即时展示**单行直投预览**，敲击回车瞬间通过原生 API 追加为首列主键块。

### 7. ★ 跨软件光标穿透直接回贴双链 (`Shift+Enter`)
- 在任意软件（Word、浏览器、微信、VSCode 等）按 `Alt+Shift+Q` 唤起罗盘；
- 检索文档 (`d:`) 或块 (`b:`)，选中后直接按下 **`Shift+Enter`**；
- 罗盘瞬时隐去并自动将焦点交还给原软件，**自动模拟光标定位并直接将思源双链 `((block_id "锚文本"))` 粘贴在当前文字光标处**，省去“复制-关闭-切换-粘贴”繁琐链路！

### 8. ★ 深度对标与超越叶归「一键记事」（连续记录防碎块粘滞 & 意图微感应 HUD）
- **防碎块粘滞时间窗口 (Continuation Window)**：默认提供 30 秒（可在偏好设置自由调节 0~600 秒）的连续记录粘滞期。在同窗口同应用下连续速记自动合并至上一条块内，彻底告别“一句话一个日记块”的碎片化痛点；
- **动态意图微感应 HUD (`MiniInputWindow`)**：按下 `Alt+Shift+S` 唤出的居中速记框键入 `!`、`@`、`?`、`#` 时左侧徽标与边框实时平滑变色感应（待办/人脉/闪卡/项目），处于粘滞期时自动亮起 `⏳ 续写合并` 提示；
- **`[[` / `【【` 知识库双链实时补全**：在速记框键入 `[[关键词` 时，3ms 异步检索思源知识库文档与重点段落，按 Tab 或点击候选词直接完成 `((block_id "标题"))` 双链闭环；
- **多行草稿微舱扩展 (Scratchpad Mode)**：在速记窗按 `Ctrl+Enter` 瞬间展开为 175px 多行记事舱，支持多行批量解包入库；支持失焦草稿防误关保护；
- **桌面图钉便签 HUD (`ShowStickyNote`) 实时双向回写**：搜索抽屉中点击 `📌 钉在桌面`，将笔记块钉在屏幕右上角供写代码或文献时对照参考；支持点击图钉切换置顶、`Ctrl+S` 即时回写思源原生块，并支持 `Ctrl +/-` 缩放阅读字号。

### 9. ★ 桌面级 0ms FSRS 闪卡 3秒微刷卡微舱 (`FSRSCapsuleWindow` · `Alt+Shift+R`)
- 深度联动思源原生 `/api/riff/` 间隔重复算法，彻底解决用户“卡片堆积不复习”的痛点；
- 按下 `Alt+Shift+R` 0ms 居中弹出 540×360 极简微舱，展示卡片正面，空格翻转答案，数字键 `1 / 2 / 3 / 4` 秒级评级（重来/困难/良好/简单），无需切换思源大窗口，碎片时间轻松刷完。

### 10. ★ 全局双链认知雷达与随身划笔穿透 (`CapsuleWindow` · `Alt+Shift+W`)
- 划选即知知识关联：在任意软件划选词汇呼出微胶囊时，以 3ms 极速反查思源 SQLite 数据库；
- 若词汇已在思源建档收录，胶囊顶栏瞬间亮起翠绿微徽章：`🔗 已收录: 《深度学习笔记》 (Shift+↵ 贴双链)`，按 `Shift+Enter` 即可将双链注入外部光标。

### 11. ★ 3D PDF 断行自愈与全网平台版权尾巴清洗 (`TextCleaner.cs`)
- 自动识别并缝合 PDF 跨行断字连字符（`word-\r\n ing` -> `wording`）；
- 自动剥离知乎、CSDN、掘金复制时附带的版权推广尾巴；
- 规范无序列表符并在中英文间自动注入优雅的盘古留白。

### 12. ★ 微软 Windows 虚拟桌面全景联动 (`WorkspaceSnapshotManager.cs` · `ws:`)
- 调用 Windows 原生 `IVirtualDesktopManager` COM 接口，将思源多窗文档、本地文件（SumatraPDF、Office、VS Code）打包为 500 字节轻量现场快照；
- 支持多任务工作现场 0ms 无感切入与还原。

### 13. ★ 开放本地工具适配：Everything / Listary / Zotero / 资源管理器自由选用 (`ToolDetector.cs`)
- **绝不绑架用户习惯**：无论是习惯用 **Listary**（快速激活检索）还是 **Everything**（全盘毫秒索引），系统均可秒级感知并设为首选引擎；
- **学术生态联动**：深度感知 **Zotero** 学术文献库与 **SumatraPDF**，支持 `zotero:` 前缀与 `zotero://` URI 原位激活调动；
- **自适应界面感知**：抽屉按钮根据当前运行与偏好动态变为 **`🔍 Listary 定位`** 或 **`🔍 Everything 定位`**，支持快捷键 `Ctrl+E` 与前缀 `listary:`、`ev:`、`find:`；
- **偏好面板状态联动**：设置页提供 Everything 与 Listary 双通道实时探针，支持一键切换。

### 14. ★ 零依赖原生轻量级 SVG 思维导图抽屉看板 (`generateMindmapSvg`)
- 告别笨重的第三方图表库，基于纯原生轻量 SVG 算法毫秒级将笔记 H1~H6 大纲解析为树状脑图；
- 优雅的三次贝塞尔平滑分支线条与色彩语义分级；每个节点均可直接点击穿透回思源定位该小节。

### 15. ★ 深度对标 Obsidian/Cubox/Readwise：0扩展双态剪藏与即时批注 (`g:`)
- **零浏览器扩展限制**：通过 Windows 底层 UI 自动化与窗口感知，0ms 嗅探 Edge、Chrome、Brave、Firefox 等全系浏览器乃至桌面客户端（微信/知乎/SumatraPDF）；
- **双态自由分流**：
  - **模式 1 (Enter · 默认)**：**文献卡片流** —— 将文章元数据、划选精粹生成大纲级嵌套列表归入今日日记或收集箱；
  - **模式 2 (Shift+Enter)**：**独立研读专页** —— 在 `/读库/` 中创建整篇独占笔记，生成思源原生文献 Callout 看板，自动挂载 `custom-clip-status="unread"` 拾遗未读分拣属性；
- **即时思考批注**：搜索框直接键入 `g: 你的思考观点`，在剪藏原文同时自动以子列表或专页批注区归档「摘录+思考」双闭环；
- **14 大主流知识平台智能元数据与标签**：深度适配微信公众号、知乎专栏/问答、B站（UP主与时长）、GitHub（Star与Owner）、arXiv、少数派、掘金、CSDN、小红书、语雀、飞书等，自动提取真实作者并注入 `#微信精选`、`#学术论文`、`#开源项目` 等智能标签；
- **防盗链外链图片自动本地落盘**：静默伪造合规 Referer 将微信公众号、知乎等易失效图床图片自动下载并上传至思源 `/data/assets/` 资产库，彻底根绝 403 访问被拒与死图。

### 16. ★ 今日记事时间轴 7 天极速日历穿梭条 (`timeline-date-shuttle`)
- 在「📅 今日时间轴」抽屉顶端搭载 7 天日历穿梭条：动态生成「今天」、「昨天」、「前天」直至过去 7 天的快速切片按钮；
- 点击任意历史日期，0ms 穿梭调取思源 SQLite 中该日记文档的全量时序流（灵感、待办、闪卡、记账），免去切入思源层层翻找历史日记之苦。

### 17. ★ 离岸应急缓冲队列详情看板与 1 键手动回写 (`OfflineQueueManager.cs`)
- 顶栏状态区新增实时感知徽标：当检测到离线缓冲速记时，自动亮起琥珀色 `📦 离线 N 条` 徽标；
- 点击直达队列看板，检视各条记录的离线暂存时间与正文，并支持一键 `[🚀 立即回写至思源]` 或 `[🗑️ 清空队列]`，网络自愈感知更加通透。

## 六、 开放外部集成规范 (AI 智能体 / 自动化脚本 / 国产大模型生态)

思源外骨骼全面拥抱开放外部调度，支持国内外各类 AI 编程助手、智能办公客户端（**WorkBuddy、ZCode、通义千问办公、豆包、DeepSeek dsh、Cursor、Claude、Antigravity**）以及本地 Python/PowerShell 自动化脚本免依赖直接驱动：

### 1. 本地命名管道直连 (`\\.\pipe\XiaoLvDesktop_IPC_Pipe`)
在后台常驻运行时，直接向命名管道发送单行指令或 JSON 信封，零网络端口占用，响应时间 `<1ms`：

- **单行文本协议**：
  ```
  SYS 💡 通过外部 AI 助手写入的思考洞见
  SYS ! 明天下午2点金雨茂物汇报
  SYS ¥42.0 瑞幸咖啡
  ```
- **结构化 JSON 信封**：
  ```json
  {
    "cmd": "SYS",
    "text": ">@周度规划模板 本周核心架构设计与优化完成",
    "extra": { "source": "WorkBuddy" }
  }
  ```

### 2. 私有协议超链接唤醒 (`siyuan-exoskeleton://` / `xiaolv://`)
支持在浏览器、Markdown 文档或国产办公客户端中点击超链接即时触发外骨骼：

```markdown

```

### 3. CLI 命令行参数盲打传参
可在任意终端中直接执行可执行程序（自动透传至已运行的后台常驻守护实例）：

